# 织记 · VCP 式记忆引擎与 AI 自进化设计

> 定调：**不接入 OpenViking，记忆层沿用 VCP 的设计路线——应用内自建「记忆引擎」**，随应用启停、零外部服务依赖。
> 理由：VCP 的整个记忆体系（分层记忆、语义引力、冷热双通道、长期沉淀）本来就是自包含实现（Node/Python/Rust + 本地库），不需要外部记忆服务；织记作为 Electron 单进程应用，把同样的事收敛进主进程，部署负担、端口管理、降级分支全部消失。

## 1. VCP 的记忆观（三条直接沿用）

1. **信息流向 AI，而非 AI 查询信息**：「引力场」在每次生成前实时计算该注入什么，不让 AI 决定去回忆什么（不知道的就永远不必想起）。
2. **记忆是一张网络，不是一堆条目**：联想沿着 语义相似 / 结构关联 / 行为脉络 流动，而非孤立关键词匹配。
3. **记忆会自我沉淀与成长**：写下是行动，想起是动力学；使用越多，注入越准、规则越贴合用户——这就是「自进化满足用户需求」的机制本体。

## 2. 记忆分层模型（自建版，对齐 VCP 粒度）

| 层 | 内容 | 存储 | 生命周期 |
|---|---|---|---|
| L0 任务上下文 | 当前生成流（导入稿、任务态、指令） | 进程内存 | 任务结束即弃 |
| L1 语义知识 | 笔记、知识点、资源文档（切块+向量） | SQLite + sqlite-vec | 长期 |
| L2 用户偏好 | 排版/公式/图片/模型/工作流偏好 | SQLite（偏好表） | 长期、可修订 |
| L3 行为事件 | 采纳/修改/重生成/纠正的完整留痕 | SQLite（行为日志表） | 中期，周期蒸馏 |
| L4 经验规则 | 蒸馏出的可执行规则（模板变量/路由/校验/检查项） | 规则表 + settings | 长期，冲突消解 |

## 3. 记忆引擎架构（Electron 主进程内建）

- **存储核心**：better-sqlite3 事实源（上表 5 类表）+ sqlite-vec 向量扩展（嵌入由 LLM API 生成，MVP 可先 JS 余弦再迁移）；全部本机、随应用启停。
- **写入子系统**：
  - 显式：用户「记住这个」→ 直入 L2/L4，记忆管理界面可查看可删。
  - 隐式：每次 AI 产出被 接受/编辑/重生成 → 行为日志（含 diff、修改部位、耗时）→ 蒸馏任务周期跑（弱模型 + 规则模板）→ 候选规则入 L4，高置信自动生效、中置信弹一次确认。
  - 知识：导入笔记切块入库 + 向量化，增删自动同步。
  - 防噪声：过短/重复/敏感内容不打标；配额 + 定期清理。
- **读取子系统（记忆包裹）**：`buildMemoryContext(任务)` = 语义召回 top-k（L1）+ 图谱邻域 + 偏好快照（L2）+ 生效规则（L4）→ 注入提示词 `{{记忆包裹}}` 槽；冷热双通道（热记忆全量在场、冷记忆折叠索引）；min_score + 时间衰减做相关性闸门。
- **联想三通道（轻量版「浪潮」，不搬 VCP 代码与算法，仅同构设计）**：
  1. 向量相似（嵌入余弦）
  2. 图谱邻接（前置/延展/类比边）
  3. 行为共现（用户总在同一语境使用的节点对）
  三通道加权融合 + 时间衰减，给出「此刻该浮上来的记忆」。

## 4. 自进化闭环（越用越懂你的完整回路）

| 步 | 动作 | 落点 |
|---|---|---|
| ① 观察 | 记录用户行为：采纳 / 修改 / 否决 / 重生成，含 diff 与耗时 | L3 行为日志 |
| ② 蒸馏 | 周期任务从日志提炼偏好规则候选 | 弱模型 + 规则模板 |
| ③ 生效 | 规则写入变量插槽 / 模板 / 校验清单 | L4 规则库 |
| ④ 反馈 | 度量每条规则启用后的修改率 / 重生成率变化 | 效果指标 |
| ⑤ 演化 | 起效晋升、无效降级停用、新旧冲突弹问用户 | 规则生命周期 |

**已有原型即是证明**：此前沉淀的偏好——公式单 `$`、图片居中 ≤800px、同讲次文件全部研读、踩坑归集 WORKFLOW_LESSONS——本就是 L4 规则。织记让它系统化：以后这类纠正**自动**被记住并生效，不再需要每次口头交代。

## 5. 边界与合规

- **自研实现**：只沿用 VCP 的记忆**设计思想**（分层、引力注入、冷热、蒸馏闭环），不复制 RiverMemo 等任何代码与算法（CC BY-NC-SA 边界）；联想算法用自己的三通道加权。
- **数据主权**：全部落本地；设置界面「记忆管理」支持查看、逐条删除、一键清空、导出 JSON/MD。
- **与知识图谱一体两面**：图谱存「知识结构」，记忆引擎存「使用痕迹与规则」；注意力包裹（关联知识）与记忆包裹（偏好规则）合并为同一次上下文装配。

## 6. 阶段分配（并入开发方案）

- **M1**：记忆 table schema（行为日志/偏好/规则）+ 三事件埋点（接受/编辑/重生成）
- **M2**：记忆包裹 v1（向量召回 + 偏好快照注入）
- **M3**：联想三通道（图谱邻接 + 行为共现）+ 冷热双通道
- **M4**：蒸馏闭环（弱模型）+ L4 规则生效 + 记忆管理界面
