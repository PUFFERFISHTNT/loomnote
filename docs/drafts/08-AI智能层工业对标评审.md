# 织记 AI 智能层 · 工业标准对标评审

> 评审对象：`docs/drafts/05-记忆系统架构方案.md` + `docs/drafts/06-源码洞察与全栈优化方案.md`
> 对标范围：Mem0 / Zep CE(Graphiti) / Letta(MemGPT) / LangGraph memory store / HippoRAG / Microsoft GraphRAG / Self-Refine·Reflexion / Vercel AI SDK·Claude Artifacts（流式 UI）/ OpenRouter Auto·NotDiamond·Martian·RouteLLM（模型路由）/ 本地化 RAG 与隐私存储趋势（2024–2026）
> 总评：**38 / 50 分**。设计水平处于「开源产品 Mem0/Zep CE」与「学院派 HippoRAG」之间——架构形态无致命短板、工程纪律超出多数同类方案；最大缺口不是算法，而是**评测驱动的证据链**：Zep 有 DMR/LongMemEval、Mem0 有 NeedleBench/LOCOMO、HippoRAG 有 multi-hop QA，织记的「效果优先」目前没有可测量的效果承诺。「思想迁移 + V1 简化」的路线判断正确，需按本文第 4 节加量化护栏。

## 1. 织记记忆架构评分表（五维，0–10）

| 维度 | 得分 | 批判性理由 |
|---|---|---|
| **摄取管线** | **8/10** | 写入链路（句级分块 85% 预算+10% 重叠 → 内容哈希幂等 → 批量嵌入重试 → Tag 提取 → SQLite+向量双落 → 后台离线重建派生物）与 Mem0 的「提取→双存」流水、LangGraph「后台写记忆」模式同构；WAL/健康自愈/资产世代化达到生产级纪律，幂等键 `uri+checksum` 设计正确。<br>扣分：①缺 PII/敏感内容过滤器——行为 diff 原文入库会经蒸馏与召回二次放大隐私面；②表结构无 scope/namespace 隔离字段，跨课程记忆会互相污染；③`tag_edges` 只有权重、无时序失效模型（用户纠错后旧关系无法显式失效）；④0.92 单一语义去重阈值有风险：余弦 0.92 会把「相似但不同」的两个事实（如两门课同一公式的不同适用条件）误合，应加同源+同 Tag 双条件；⑤自研 tokenizer 估算存在系统性偏差风险，需用目标模型 tokenizer 校验。 |
| **召回质量设计** | **7/10** | 三通道（向量/图谱邻接/行为共现）过取 k×3 → 双轨去重 → 单步传播 boost → 原文锚定 → 特征加权重排，主干与 HippoRAG（PPR 图检索）、Zep（图+语义双召回）、GraphRAG（局部+全局）同构。「单步传播不做多跳」有 HippoRAG 背书（单步已与 IRCoT 迭代检索质量相当，且快 6–13×、省 10–30×）；「原文锚定、禁摘要替原文」是正确防坍缩机制。<br>扣分：①**全线没有指标基准与回归集**——最大黑洞，效果主张不可证伪；②EPA 近似特征（logicDepth≈专业词密度、novelty≈残差能量比）无验证方法，等于手拍+宣称；③boost 1.2–1.4、k×3 等权重全手拍且无日志校准回路；④行为共现通道冷启动=早期输出纯噪声（需最小支持度）。 |
| **自进化闭环可行性** | **7/10** | 记录行为→离线蒸馏→shadow 灰度→高置信自动/中置信弹问→效果度量→晋升/降级，是 Reflexion「口头强化学习」的**产品化离线版**，且比多数框架更工程：shadow 状态避免了「自信的错反思直接生效」，规则带 `source_event_ids` 可溯源、资产世代化可回滚——工程层级高于自研派。<br>扣分：①效果度量的**归因难题被低估**：修改率下降可能是模型供应商升级/任务难度变化等混杂因素，方案无对照组设计（应做规则级影子 AB）；②「弱模型蒸馏→规则教强模型」是链路最脆环节（Reflexion 教训：反思可能是自信的错误），必须证据约束；③distillRules 无频率/配额/成本预算；④规则冲突消解只写了接口、未定义裁决逻辑与仲裁存储。 |
| **隐私与本地化** | **9/10** | 全本地 SQLite+sqlite-vec、零外部服务依赖、随应用启停——精确踩中 2025–2026 local-first/on-device IR 趋势；上下文快照可审计 + 记忆管理界面（看/删/清空/导出）构成隐私可治理闭环，超出多数开源记忆方案的成熟度；飞书/Notion 仅作备份通道的边界清晰。<br>扣分（1 分）：①嵌入向量生成与弱模型蒸馏默认走云端 Provider = 记忆内容明文出设备，方案未显式声明也未给「本地嵌入/不出网」开关；②同步通道未定义排除清单（行为流水/规则/快照三张表应默认永不云同步）；③行为留痕与快照保留期未写。 |
| **工程复杂度（是否过度设计）** | **7/10** | V1 简化原则（EPA/Ω 全量明确降级 P2）、20 行原型增益门槛、P0/P1 优先级矩阵、验收红线——都是真实的反过度设计纪律。「数学内核 TS 重写、代码零复制」是正规的思想迁移动作。<br>扣分：①「架构形态照搬」合计超 1.3 万行的记忆体系（schema/管线/资产化/审计四子系统），M1–M4 实际是 2–3 季度的纯基础设施投入，收益要等蒸馏闭环跑起来才可见，与「演示模式」抢人力；②CC BY-NC-SA 边界构成长期合规债，每次改动需自查派生性；③「思路展开」面板（P1）与演示模式争 token 且价值未验证；④检查点每 20 delta 全量快照 + 可观测三件套同时上，本地盘与维护面压力大。 |

**分维小结**：摄取 8 → 召回 7 → 自进化 7 → 隐私 9 → 复杂度 7。强在本地化与工程纪律，弱在「一切可用机制均无基准背书」。**第一优先级不是补算法，是补评测。**

## 2. 工业标准差异表

| 对标系统 | 同构点（好） | 差异点 | 值得学吗 |
|---|---|---|---|
| **Mem0**（arXiv 2504.19413） | 提取/固结两阶段（↔ recordBehavior→distillRules）；向量+图双存储；后台任务合并 | Mem0 的固结 = 语义聚类把具体记忆升级为主题记忆（阈值触发），并靠 NeedleBench/LOCOMO 证明收益；织记缺「主题记忆」中间层与外部基准 | **是**。①distillRules 前先做「事实抽提→按语义阈值聚类固结（建议 8 条/域触发）→从聚簇生成规则」，规则不直接从 raw diff 生成，去噪+省 token 双收；②采购 NeedleBench/LOCOMO 之一做年度外部对照 |
| **Zep CE / Graphiti**（arXiv 2501.13956） | 图谱+语义双召回、行为记忆、社区摘要（↔ MOC）、生产级态度（Thoughtworks 雷达在途评估） | Graphiti 双时序模型（valid_at/invalid_at）+边失效+实时递增建图；Zep 公开基准：DMR 94.8%（胜 MemGPT 93.4%）、LongMemEval 精度 +18.5%、延迟 −90%；织记仅静态权重边+离线世代重建 | **是**。①M3 给 tag_edges 加 valid/invalid 双时间戳与失效降权——用户纠错理解是高频事件，旧边必须能失效；②「社区摘要」只学思想、用统计版实现（勿学 GraphRAG 全图 LLM 摘要）；③引 LongMemEval 做时序问答回归 |
| **Letta / MemGPT + Sleep-time Compute**（arXiv 2310.08560 / 2504.13171） | 分层记忆（核心/归档 ↔ L0–L4）、注入预算守卫与归档唤起（↔ 冷热+折叠）、后台睡眠整理记忆（↔ 世代重建/蒸馏） | Letta 2025 把睡眠时间升级为**睡眠计算**：预计算未来查询的答案，测试时计算 ↓5×、准确率 +13–18%、同语境多查询摊薄 2.5×；且收益与**查询可预测性正相关**。织记世代重建只重建索引不预计算内容 | **非常是——织记是睡眠计算的最佳宿主**。FSRS 排期下的复习/测验查询高度可预测（到期卡、薄弱点可枚举），M4 后把蒸馏任务升级为「温习预计算」：为到期项预生成摘要/演示骨架缓存。论文结论直接变现为差异化产品特性 |
| **LangGraph memory store**（语义检索 2024-12） | 命名空间+语义检索+「后台写/工具写」双模式；query 检索+装配（↔ buildMemoryPackage） | LangGraph 把记忆泛化为 KV+语义索引+filter，纯检索零演化，决策交给图节点；织记内建「引力场」自动注入，表达力强但黑箱度更高 | **是**。①memories/rules/prefs 加 namespace/scope 字段（全局/课程/项目三级）+召回 filter 前置，防跨域污染、支持按域清空；②保持「后台写入」形态 |
| **HippoRAG**（arXiv 2405.14831，NeurIPS'24） | 图谱+图传播联想（共现核传播/图谱邻接 ≈ PPR）；「单步检索足够」直接背书织记不做多跳迭代 | HippoRAG 是 LLM 抽取的开域实体图+PPR，有 multi-hop QA 基准最高 +20%；织记图谱是笔记节点+tag 边、检索单元是 chunk | **部分值得**。①建 20–30 条「跨笔记多跳追问」自有回归集并入发版门禁；②不必学开域实体图提取（成本高易错，笔记场景 tag/边足够） |
| **Microsoft GraphRAG**（arXiv 2404.16130） | 全局视野（社区摘要+全局搜索 ↔ 分层摘要/MOC/冷热通道）、局部分流思想 | GraphRAG 全局检索是查询期社区摘要 map-reduce，每次重跑大量 LLM 调用；织记概要层是写时生成的轻实现 | **否**。全图 LLM 摘要+查询期 map-reduce 对桌面单用户产品不划算；织记写时生成+统计版 MOC 已是正确轻量化——保留本结论防团队因 GraphRAG 名声而上缴成本 |
| **Self-Refine / Reflexion**（arXiv 2303.17651 / 2303.11366） | 自我反馈闭环；织记把在线反思离线化为蒸馏闭环；shadow 灰度优于 Reflexion 直接生效；规则溯源 = episodic buffer 结构化版 | Reflexion 的反思每次在线生成、token 贵、不可跨任务复用；织记规则可复用/审计/回滚 | **是（作为防陷阱指南）**。①反思必须证据约束：蒸馏提示词强制「只从 diff 可见证据提炼、禁止泛化」，每规则 ≥2 独立正样本；②迭代会坍缩：蒸馏保留「生成→校验→保留」三步，产出后由二次弱模型校验可证伪性与副作用；无效规则自动降级停用（现有生命周期机制执行到位） |
| **流式 UI：Vercel AI SDK / Claude Artifacts / A2UI** | 单 SSE 流+流内工具续写（:::tool 回环 ≈ AI SDK 流内工具渲染）；「独立可迭代内容识别+分屏渲染」（↔ 正文/演示双通道与演示判定）；双缓冲 iframe 优于 Artifacts 整卡全量重写（后者 token 浪费被广泛诟病） | ①Anthropic 沙箱 = 独立域+同源策略+CSP（禁外部脚本/fetch、图片 data: 白名单），织记只写了 iframe+结构校验器，未写 CSP 与 Electron 原生能力封禁；②Anthropic 用 Generator-Evaluator 循环+Playwright 实测评分治理「AI 塑料感」，织记校验器只查结构不查美学；③A2UI 协议给出结构化 UI 路线（LLM 出 JSON AST、前端渲染组件树），安全稳定性更高 | **三条分级采纳**。①M2：演示 iframe 独立 session + CSP 禁远程脚本与网络、图片白名单——抄 Artifacts 安全骨架（Electron 里沙箱做错后果比 Web 更严重，生成的代码可触 Node/文件系统）；②评估器循环降级为「快照级离线抽查」（无头截图+既有校验器），不上在线评估模型；③A2UI 式 JSON 契约作为模板备选输出模式（演示组件库化后稳定性最优），P+ 评估 |
| **模型路由：OpenRouter Auto / NotDiamond / Martian / RouteLLM** | 动态降档省 token 目标一致；织记「EPA 特征→决策表」是无监督启发式，零训练数据依赖，契合本地产品 | RouteLLM 用偏好数据训练路由器：矩阵分解版以 14% 强模型调用达到 95% 质量、比 Martian/Unify 商业路由器便宜 40%；NotDiamond 开源 RoRF（随机森林路由）；OpenRouter Auto 靠市场使用数据+质量信号；PitchBook 2025 发出灵魂拷问「纯路由是否死胡同」——强模型降价正在吃掉路由差价 | **是，但定位要校正**。①决策表参数不能永远手拍：M4 有了行为日志后，用「(特征, 档位, 结果质量)」三元组离线校准权重（RouteLLM 偏好拟合的本地版）；②**别把路由当卖点**只当成本优化器（PitchBook 警告）；③更该学 OpenRouter 的响应缓存：同查询特征+同模板组合命中本地片段缓存 |

## 4. 三大风险（量化建议）

### 4.1 过度工程
- **症状**：在移植一整套 VCP 体系（四个子系统）的同时自研扩展，M1–M4 与演示模式争人力，收益后置。
- **量化护栏**：
  - 保留「20 行原型测试增益」门禁并写进 CI/里程碑验收（现有纪律，执行到位即可）；
  - **P0 机制数红线 ≤6**：流内回环 / 渐进渲染 / 查询特征预分析 / 健康自愈 / 降档路由 / 演示沙箱——Ω 泛函、EPA 全量、思路展开面板全部 P+；
  - **删除测试**：每个 M 阶段末尾自问「删掉该机制，验收红线还成立吗」，不成立才保留；
  - 检查点改差异快照：落盘每秒 ≤1 次、单任务 ≤20 份，防本地盘膨胀。

### 4.2 Token 成本
- **量化建议**（默认值全部可配置）：
  - **记忆包裹绝对预算**：默认 ≤ min(1,200 tokens, 上下文窗口 10%)，硬帽 1,600——不要沿用 85% 比例制（比例随窗口长大而失控）；折叠块摘要 ≤80 tokens/块；
  - **注入分层默认**：熟题（coverage 高）≈300 tokens（主题摘要+偏好+规则）；novelty 高才放开全量关联 ≈1,200；
  - **流内工具回环 ≤3 次/任务、坏段重写 ≤2 次/任务**，超限自动转「后台补充」不再续流；
  - **蒸馏成本帽**：弱模型 1 次调用/事件、每周批处理、每批 ≤200 事件；固结阈值触发防高频；
  - **响应缓存**：查询特征+模板组合命中本地片段缓存（OpenRouter caching 思路）；
  - 「思路展开」面板默认关闭。

### 4.3 记忆噪声 / 隐私
- **噪声闸门**：
  - 入库：语义去重 0.92 必须叠加「同源+同 Tag」双条件；行为共现建边最小支持度 = 2；
  - 召回：min_score 默认 **0.40**（可配 0.30–0.60）；过取 k×3 去重后单通道输出 top-8~16；时间衰减半衰期 14 天与热窗口对齐；
  - 规则库：同时生效 **≤20 条**，超限自动归档+提醒清理，防规则互搏；
  - 蒸馏：抽取/生成两步校验，无证据不成规则、单事件不成规则。
- **隐私护栏**：
  - **默认不同步三张表**：behavior_events / rules / audit_snapshots 与 diff 原文永不进入飞书/Notion 同步与导出包；
  - 留痕保留期：行为流水默认 30 天（月度蒸馏后聚合归档），快照滑窗 5 份、保留 ≤30 天；

  - **补回防噪声条款**：ingest 与 distill 两端各加一道轻量 PII 过滤器（正则+实体规则，本地执行）——早前 OpenViking 版有、自建版删掉了。
