# 织记 LoomNote · 产品方案 v1

> 形态：全新独立桌面应用（Windows + macOS），自有 UI、自有工程；底层内嵌 AI 引擎（headless 本地服务）；与 DSH 桌面完全解耦。

## 1. 产品定位与形态边界

- **一句话定位**：把「原始资料」整个交给 AI，产出**能看（多格式渲染）、能演示（动态 HTML）、能考试（交互题目）、能联网（知识图谱）**的活笔记。
- **边界三铁律**
  1. 它是应用，不是插件：用户看到的是完整产品——安装包、启动、沉浸式笔记工作台。
  2. harness/引擎只是底层：以 headless 方式内嵌为本地常驻服务，对外只暴露控制协议，用户无感知。
  3. 内容主权在本地：笔记、图谱、题库先落地本地（SQLite + 文件资源库），云端仅是同步副本。

## 2. 设计三原则

1. **MD 为底，HTML 为面**：唯一事实源是带扩展语法的 Markdown IR；展示层由 AI 按知识点需要生成 HTML，普通内容走排版卡，需要演示的知识点生成动态 HTML 组件。
2. **一切皆可渲染**：md / html / pdf / word / excel / 图片 / URL 全部解析进同一中间层，按通道分流渲染，所见同源。
3. **笔记会生长**：新资料进来不整本重写，AI 只做三件事——找接缝（向量比对）→ 出变更集 → 合并前打快照，可预览、可回滚。

## 4. 系统架构

四层：

- **界面层**：React + TypeScript + Vite，Electron 桌面三端（本阶段 Win+Mac）+ Web 端同代码库。
- **应用核心服务**（本地常驻）：MD 渲染引擎、解析管线、图谱引擎、复习引擎、同步适配器。
- **AI 引擎层**：headless agent 运行时（编排 + 工具注册：文件解析/OCR/图表生成/外部 API），LLM 走火山方舟。
- **数据层**：SQLite（节点/边/题目/FTS5 全文）+ 向量索引 + 本地资源库；飞书/Notion 仅作同步副本。

与 DSH 的关系：DSH 桌面继续独立使用；已验证能力按下述方式进应用——飞书文档读写逻辑→飞书同步适配器模块；modlens 视觉识别→应用内 OCR 服务；VCP 渲染纪律→应用内 iframe 沙箱渲染规范；undo 快照思路→应用内版本系统。**经验全部复用，形态彻底独立。**

## 5. 核心技术实现

### 5.1 内容模型：Markdown IR
标准 md + 五类扩展：`$$…$$` 公式（导出飞书降级单 `$`）、```mermaid、`[[双链]]`、`:::toc`/色块（与飞书标记同构）、front matter（知识点 id/标签/难度/关联边/来源）+ 「演示插槽」占位。IR 保证任意编辑器可开、可 Git 版本化、导出只降级不重写。

### 5.2 解析管线

| 源格式 | 解析实现 | 智能增强 |
|---|---|---|
| PDF | pdfjs-dist 提取文本+版面坐标；插图按坐标框裁剪（参考已验证 zoom 2.6~3.4 经验） | OCR + 视觉模型逐张目检（无切边/渗字）；公式识别为 KaTeX |
| Word | mammoth 简单转换 / python-docx 复杂抽取 | 章节结构重建、目录自动生成 |
| Excel | SheetJS → md 真表格；数值列可转 SVG 图表 | AI 概括生成「结论块」 |
| 图片 | OCR（视觉模型）→ 结构化文字与版面 | 板书/框图/手绘由 AI 重绘为矢量 SVG |
| MD/HTML/URL | 清洗页眉页脚广告后直入 IR | 自动打来源标记与抓取时间 |

### 5.3 三模式渲染引擎

| 模式 | 用途 | 实现 |
|---|---|---|
| 正文模式 | 常态阅读 | markdown-it 插件链 + KaTeX + Mermaid，表格/色块/目录块成品化排版 |
| 演示模式 | 「看懂了才算学过」的知识点 | AI 生成 HTML5 片段，在 **sandbox iframe + CSP** 内渲染，事件经白名单桥接；纪律：唯一根容器、样式前缀隔离、结构扁平、动画只淡入、交互走桥接 |
| 源码模式 | 精确编辑/排查 | CodeMirror 6，双栏实时预览，双链与 IR 指令补全 |

### 5.4 知识图谱与增量合并
存储：SQLite 节点表+边表（前置/延展/类比/应用/来源）+ 向量列 + FTS5。表现：Cytoscape.js + fcose 力导向画布。检索：语义（向量）/ 图谱遍历（前置链、对偶比较）/ 全文。**增量更新协议**：新资料 → 向量比对 → AI 产出变更集（增/改节点、建边、标冲突）→ 界面 Diff 预览（绿增红删）→ 一键批准 → 自动快照，任意步可回滚。附 MOC 自动生成与孤岛检测。

### 5.5 复习与考试
题目结构化 JSON（题型/题面/选项/答案/解析/关联知识点/难度）→ 交互组件即时判分+错因解析 → 错误回灌图谱「薄弱」标签 → FSRS 排期（ts-fsrs）→ 每日复习队列。抽认卡/章节测验/全库自测三种粒度。

### 5.6 平台集成
- **飞书**：官方 OpenAPI（应用凭证、docx 读写、drive、图片上传）；已沉淀约束——公式只单 `$`、图片 ≤800px 居中等比、写接口 3 次/秒分批、真实写入前先建副本。
- **Notion**：notion-sdk-js（页面/块/database/md 官方转换），题库与错题本落 database。
- **LLM**：火山方舟 Coding/Agent plan；结构化输出 JSON Schema；prompt「角色/步骤/检查项」模板套件；分片 + 向量去重 + 只算增量控制成本。

### 5.7 桌面技术选型
**Electron + React + TypeScript + Vite**：Node 生态直上（pdfjs、sqlite、引擎 sidecar）、打印/导出成熟、跨端签名分发链路短；Web 端同代码库。备选 Tauri 2（包体小 80%，前期 Rust 成本高）——V1 Electron，站稳后可平移内核。

## 7. 关键风险与对策

- **演示渲染稳定性**：iframe 沙箱 + CSP 白名单 + 渲染纪律，生成后 DOM 自检，不合格自动重生成。
- **引擎与界面解耦**：AI 任务走任务队列，界面可见进度、可取消；引擎崩溃自动拉起断点续跑。
- **AI 质量波动**：结构化输出 + 模板套件 + 一键重试；生成全程留痕可回退。
- **Token 成本**：分节分片、向量去重、增量优先，绝不整库重算。
- **数据安全**：本地库 + 快照 + 可导出的明文 Markdown。
- **飞书/Notion 限频与格式差**：沿已有实测约束，排队 + 重试。
