## 2. 对标差异说明（明确不做的）

1. **思维笔记/无限画布白板**（飞书）：图谱画布已承担「无限联想」职责，不另做白板；若真需要，图谱画布后续可加自由节点模式。
2. **多人实时协作与权限体系**：单机本地优先的产品边界内，多人协作属账号体系之后的远期项；以飞书/Notion 双向同步做「协作代办」。
3. **Bitable 级公式/自动化工作流**：不做数据库脚本；AI 增强取代「结论/汇总」类需求。

| AI 增强 | 说明 | 阶段 |

| 表格 → 结论块 | Excel/md 表由 AI 生成「这表说明了什么」 | M2 |
| 错题归因薄弱点 | 判分回灌图谱，薄弱节点自动升高复习权重 | M4 |

| 增量知识合并 | 新资料找接缝、出变更集、可审可撤地并入网络 | M3 |

## 4. 阶段分配结论（并入开发方案）

- **M1**：块套装 + 目录块 + 模板库（基础） + URL 导入 + 图片规范
- **M2**：折叠块/色块全量、AI 整理、演示模式、结论块
- **M3**：双链/反链/图谱/MOC/标签面板、多维视图（表格·看板）、历史版本、增量合并
- **M4**：复习日历/统计面板、Cmd+K 全局搜索、导出、图标封面
- **延后**：评论批注、发布分享、多人协作、白板、移动端
