**结论**：VCP 记忆 = **写入层（分块·嵌入·Tag·资产）→ 召回层（多维候选 6 路 → 传播 → 结构重排 → 直锚读出）→ 注入层（预算修剪 + 折叠 + 快照审计）**，外加贯穿全链路的**资产化沉淀**（矩阵、残差、基线的世代版本管理）支撑自进化。

## 2. 数据流全景

**写入**：文件监听 → 分块（85% 预算 + 10% 重叠）→ 幂等去重（内容哈希）→ 嵌入 → Tag 提取 → 双落（SQLite 真相 + 向量索引基线）→ 静默窗口后台重建派生物（tag 共现矩阵、tag 残差资产、正交基）——重计算全部离线，在线检索只做查表。

**召回**：query 向量化 → 分析（逻辑深度/熵/覆盖度）→ 候选超集（向量多场 KNN ×4 + BM25 + 直锚，全部过取 k×3）→ 去重（hard+semantic）→ 共现核传播（核心 tag 沿 tag 图激活，boost 1.2–1.4×）→ 残差金字塔解释能量（90% 截断）→ 成对几何修正（相对拓扑/曲率）→ 结构证据排序（Ω：河网是否真正形成）→ 有序原文读出。

**注入**：contextManager 修剪（硬保留 system、规则 User、最后一轮）→ 无关内容折叠成 `阈值+摘要` 块 → 最终上下文快照留档。

**进化**：① Agent 写记忆是行动（日记、Tag 是叙事河床）；② 资产包不可变 + 世代版本，任何重算都是「新版本一次发布」；③ 冷热分离；④ 跨空间联想发现新关联。

## 3. 十个关键机制与织记接法

| # | VCP 机制 | 织记接法（V1 简化原则） |
|---|---|---|
| 1 | 残差金字塔：主题→要点→细节三级能量分解 | 保留三级粒度用于「记忆包裹」分卷：主题摘要常驻、要点按需、细节折叠 |
| 2 | EPA 世界观/逻辑深度 | 用行为画像替代：修改率、常用模型、任务类型分布、时段习惯 |
| 3 | 候选超集 6 路过取 | V1 三通道：向量召回 / 图谱邻接 / 行为共现，各过取 k×3 后统一去重 |
| 4 | 共现核传播（信息沿 tag 图流动） | 边权重一步传播 + 核心 tag（当前笔记标签）加权 |
| 5 | Ω 结构秩序排序 | 织记 rerank 特征加权：结构分（关系路径）+ 新鲜度 + 强度 + 距离 |
| 6 | 直锚读出（候选不重嵌入、原文锚定） | 原文永远随候选返回，禁止摘要替掉原文 |
| 7 | 折叠协议（阈值+摘要块） | 同构：预算内全量，超出部分折叠为「阈值 + 摘要」索引块 |
| 8 | 资产世代化（immutable + 版本 + 一次发布） | 规则/偏好/索引/画像全部带版本号，重建即新版本，旧版本可回滚 |
| 9 | 冷热双通道（TDB 冷库） | 热：近期学习/薄弱/高频全量在场；冷：归档表 + 折叠索引，按需唤起 |
| 10 | 上下文快照审计 | 每次装配记忆包裹前落快照（滑窗），记忆管理界面可回看「AI 当时看到了什么」 |

## 4. 织记记忆引擎实现方案

### 4.1 模块划分（packages/memory，TypeScript，无原生依赖）

```
packages/memory/src/
├── chunker.ts        # 句级切分：85% token 预算、10% 重叠、标点强制断（仿 TextChunker）
├── embeddings.ts     # 嵌入批处理 + 余弦 + 缓存（仿 EmbeddingUtils；走 Provider 框架「向量」角色）
├── dedup.ts          # hard（内容哈希）+ semantic（相似度阈值）双轨（仿 ResultDeduplicator）
├── store.ts          # SQLite：memories/tags/tag_edges/sources/behavior_events/rules/prefs/artifacts
├── layers.ts         # 三级粒度：chunk 层/主题摘要层/全局层（残差金字塔的语义版）
├── recall/
│   ├── channels.ts   # 三通道候选：vector（k×3）/ graph（邻接）/ behavior（共现），各带权重
│   ├── boost.ts      # 核心 tag 加权 + 边单步传播（共现核的简化）
│   ├── anchors.ts    # 直锚读出：候选原文锚定、不重嵌入
│   └── rerank.ts     # 结构分 + 新鲜度 + 强度 + 距离，特征加权排序（Ω 的简化）
├── fold.ts           # 折叠块协议（同构 foldProtocol，织记标记）＋ 预算守卫（contextManager 规则）
├── packager.ts       # buildMemoryPackage：召回 → 折叠 → 装配 → {{记忆包裹}}/{{注意力包裹}}
├── rules.ts          # L4 规则库：新增/生效/冲突消解/效果指标（自进化执行层）
├── audit.ts          # 上下文快照（滑窗 5 份）
└── engine.ts         # 门面：ingestDocument / recordBehavior / recall / buildMemoryPackage / distillRules
```

### 4.2 核心数据表

```sql
memories(id, source_id, kind[chunk|summary|preference|rule], layer[1..3],
  content, tags_json, embedding_blob, chunk_index, strength, access_count,
  last_access_at, created_at)
sources(id, uri, kind, checksum, ingested_at)          -- 幂等键 = uri+checksum
tags(id, name, embedding_blob)                          -- tag 真相库
tag_edges(a, b, weight, created_at)                     -- 共现/关联边（传播用）
behavior_events(id, at, kind[accept|edit|regenerate], target, diff_brief, meta_json)
rules(id, kind, body, source_event_ids, confidence, status[active|shadow|off], ver)
prefs(key, value_json, ver)                             -- 偏好快照（带版本 = 资产化）
artifacts(id, kind, ver, payload_json, created_at)      -- 派生物（画像/索引基线）世代管理
audit_snapshots(id, at, request_brief, package_json)    -- 上下文快照（滑窗保留）
```

### 4.3 核心 API（引擎对外契约）

- `ingestDocument(sourceUri, text)` → 分块、去重、嵌入、Tag、分层摘要，幂等可重跑
- `recordBehavior(event)` → 事件入流水；`distillRules()` → 弱模型 + 统计双路提炼候选规则（高置信自动、中置信弹问）
- `recall(query, ctx)` → 三通道过取 → 去重 → boost → 锚定原文 → rerank → 有序候选
- `buildMemoryPackage(query, ctx, budgetTokens)` → recall + 图谱邻域 + 偏好快照 + 生效规则 → 折叠装配 + 审计快照
- `getActiveRules()` / `getPrefs()` → 供引擎提示词变量注入

### 4.4 关键参数（默认值，全部可配置）

token 预算 85%（安全边际）、分块重叠 10%、过取倍数 k×3、语义去重阈值 0.92、核心 tag boost 1.2–1.4、热窗口 14 天、折叠默认阈值 0.6、快照滑窗 5 份。

### 4.5 测试计划（单元级，注入假嵌入器）

chunker 边界（超长句/空文本/重叠正确性）；dedup 双轨；recall 三通道合并与去重、自身排除、boost 单调性；fold 预算守卫与折叠还原；rules 冲突消解与生命周期；audit 滑窗淘汰。

## 5. 阶段安排（并入 03 里程碑）

- **M1**：store + chunker + embeddings + dedup + 三事件埋点（行为流水）
- **M2**：recall v1（向量通道 + boost + 锚定）+ packager（{{记忆包裹}} + 偏好快照）+ 预算守卫
- **M3**：图谱邻接通道 + 行为共现通道 + 分层折叠强化 + 资产世代化（画像/索引版本）
- **M4**：distillRules 蒸馏闭环 + 规则生效与效果指标 + 记忆管理界面 + 上下文快照审计

验收红线（增补入 03 §8）：用户纠正一次偏好（如“公式用单 `$`”）→ 之后同类生成自动遵守；记忆包裹装配前后快照可回看；全部记忆随应用启停、零外部服务。
