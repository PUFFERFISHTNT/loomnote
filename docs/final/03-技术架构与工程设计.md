## 1. 分层架构

```
界面层   React + TS + Vite（Electron 壳；Web 端同码）
   ↕ typed IPC（contextBridge，事件流）
核心服务层（主进程，本地常驻）
   ├ 渲染引擎（三模式） ├ 解析管线 ├ 图谱引擎 ├ 复习引擎（FSRS）
   ├ 同步适配器（接口+桩） ├ 存储/资源库/健康自愈 └ 资产世代化
   ↕
Harness Agent 运行时（同进程独立模块，工具注册表 + agent loop）
   能力：联网搜索/网页抓取、文件读写、OCR 识图、知识检索、图谱查询、
        公式计算、笔记生成器、演示生成器、题目生成器…
   ↕ LLM Provider 框架（任意 OpenAI 兼容 / Anthropic / 自定义端点）
数据层   SQLite（业务+记忆+WAL）+ 资源库 + 向量扩展 + 导出
```

## 3. 双端策略（Windows + macOS）

## 5. Harness Agent 运行时（新定调核心章节）

**定位**：织记的 AI 引擎本体 = 内嵌 agent 运行时（主进程内独立模块），不是模型客户端。

**实现策略（改判 D8/D15）**：直接复用 DSH 官方 MIT 包（npm 依赖、锁 0.1.x、与 DSH 桌面同款代码）——`dsh-agent-loop`（agent 循环）、`dsh-llm-pi-ai` + `@earendil-works/pi-ai`（Provider/SSE/工具调用）、`dsh-tool-web` 与 `dsh-web-search-deepseek`（联网）、`dsh-llm-retry / dsh-token-meter / dsh-timeout / dsh-user-approval / dsh-compaction`（重试/预算/超时/审批/折叠）；在 cordis 微型 ctx（MIT 事件/DI 容器）内装配。织记只写薄封装层 `LoomnoteAdapter`：学习场景工具注册、事件流→UI 投影、记忆引擎接入、审批门 UI 对接。**明确不引入**：cordis 插件体系/插件市场、`dsh-client-*` UI 包、`dsh-desktop-*` 壳、`dsh-sandbox`（自有安全模型）。

### 5.1 Agent Loop（复用 dsh-agent-loop）

以 `dsh-agent-loop` 为循环本体（规划-行动-观察、事件流、预算/超时/重试、双协议工具调用、检查点），织记负责：cordis ctx 装配、注册学习场景工具、订阅事件流投影到 UI、把记忆包裹/注意力包裹经 `{{}}` 插槽注入系统提示词。**回退方案**：若其 Session 抽象与织记任务模型（导入→整理→演示→题目）语义不匹配，以 pi-ai + dsh-llm 为积木自写 ~200 行薄 loop（两条路均已验证可走）。

- **双协议工具调用**（继承自 dsh loop）：模型支持 Function Calling → 原生 tools schema；不支持 → 文本标记协议（`:::tool 名 {JSON5}` 容忍解析，坏块降级）；共用同一工具注册表。
- **联网能力**（复用 `dsh-tool-web` + `dsh-web-search-deepseek` / `dsh-web-fetch-http`，turndown→md）：「联网查证」默认开启，可全局/按任务关闭。
- **事件流**：plan / tool-start / tool-result / delta / done / error / checkpoint（dsh loop 发出，织记投影到 UI）。

### 5.2 工具注册表（tool spec = name/description/parameters/risk/needsApproval）

| 类别 | 工具 | 风险 | 审批 |
|---|---|---|---|
| 网络 | web_search / web_fetch | 外发 | 默认放行（可全域关闭） |
| 本地读 | read_note / recall_memory / query_graph / read_file | 无 | 免审 |
| 本地写 | write_note / create_nodes / merge_changeset | 中 | 变更集→用户审批 |
| 生成 | generate_note / generate_demo / generate_quiz / render_chart | 低 | 免审 |
| 媒体 | ocr_image / crop_image | 低 | 免审 |
| 计算 | calc（解析器实现，V1 不引入任意代码执行） | 低 | 免审 |
| 外部 | feishu_push / feishu_pull / notion_* | 高 | 必审（P2 启用） |

扩展机制：工具清单化注册（manifest 格式），后续可开放第三方工具（对齐 VCP 插件清单思想）。

### 5.3 流内工具回环与可观测

工具在 SSE 流内执行后模型续写同一条流（VCP 模式）；所有 tool 调用的入参/结果脱敏落盘 → 「agent 动态」面板（V2 工作台）+「生成流回放」（06 评审后完善的审计）。

## 6. 渲染引擎（三模式 + 实时生成）

| 模式 | 实现要点 |
|---|---|
| 正文 | markdown-it 全插件链 → DOMPurify → 设计系统；[[双链]] 可点；`:::demo` 插槽内嵌演示组件 |
| 演示 | AI 生成 HTML 片段 → 沙箱 iframe 三件套（`srcdoc` + `sandbox="allow-scripts allow-forms"`（永不加 allow-same-origin）+ 不可变 meta CSP `default-src 'none'`）+ MessageChannel 私有端口桥 → 纪律校验器（唯一根/前缀隔离/扁平/无 backdrop-filter/动画只淡入/**外联资源=0**）→ 坏段只重写坏段 |
| 源码 | CodeMirror 6 + 实时预览 |

**实时管线**：SSE（半包解析 + 断点续传 + 错误码映射）→ 流内工具回环 → 三层缓冲（增量 IR → 50–80ms 防抖 → keyed 分块 memo）→ 演示帧双缓冲（旧帧可交互/新帧原子替换 + 帧预算跳帧）→ 纪律校验下沉 → 检查点分支（回放/检查点容量轮转）；明确不引 morphdom；首帧 ≤2s。

## 7. 可靠性与安全（VCP 工程纪律移植）

- **存储健康自愈**：开库五条 PRAGMA（WAL + synchronous=NORMAL + busy_timeout=5000 + wal_autocheckpoint=1000 + journal_size_limit 上限）；退出/备份/迁移前 checkpoint(TRUNCATE)；VACUUM INTO 轮转备份 N=3；冷启动 quick_check→integrity_check；单写者硬约束；损坏隔离区重建。
- **Electron 安全基线**：成文于 `docs/final/07-安全基线.md`——沙箱三件套、will-navigate 拦截、setWindowOpenHandler 全拒、typed IPC（zod）、主页面与演示 iframe CSP 分治、safeStorage 密钥、CI 静电分析门禁。
- **资产世代化**：图谱指标/MOC/共现索引/画像=不可变资产包+世代版本+原子发布+后台防抖重建；请求路径零重算。
- **权限门禁**：危险工具必审 + 时效白名单；AI 只产草稿变更集，永不自批。
- **可观测**：上下文快照审计（滑窗）、生成流回放、日志分级；密钥走系统钥匙串，日志脱敏。
- **查询特征预分析**：每任务前算 logicDepth/entropy/coverage/novelty → 动态选模型档位/注入预算/是否生成演示（05 记忆引擎协同）。
