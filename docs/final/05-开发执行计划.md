## 2. 验收标准（开发测试版 · 11 条）

1. **双端可跑**：macOS 与 Windows 全新克隆 → `pnpm i && pnpm dev` 成功；CI 矩阵绿。— ✅ mac 实测冒烟；Windows 待 CI 首跑
2. **导入**：10 页以上 PDF 30s 内解析；正文/公式/插图落库正确。— ✅ 真实讲义 e2e（8916 字符 <1s）；插图裁剪属 M3 深化
3. **AI 整理**：单讲次自动产出 主标题/目录/章节/速记卡/自测；流式过程界面可见。— ✅ 用户实测 SDST2601 讲义整理成功 + 实时预览
4. **演示**：≥3 个知识点生成 HTML5 演示；沙箱内交互正常、无样式泄漏；坏段被拦截只重写坏段。— ✅ 内嵌 M/M/1 排队动画截图+modlens 确认；坏段重写待实测
5. **Harness Agent**：agent 能自主规划并多步调用工具（含联网搜索/网页抓取）完成有依赖的复合任务；过程全程可见、可打断可分支；危险工具必审批。— ✅ loop/双协议/工具/中断单测；联网抓取与审批门实测定级 M3
6. **图谱**：≥20 节点自动入库；画布缩放/搜索/侧卡；增量导入出变更集可审可撤。
7. **复习**：≥5 题即时判分；错题下调节点 mastered 并进入 FSRS 排期。
8. **版本**：改笔记→快照→Diff→恢复全链路无损。
9. **本地主权**：断网可启可编（agent 降级为无联网模式）；笔记可整库导出 md+assets。— ✅ JSON 兜底 + 本地优先架构；导出按钮待 M3
10. **记忆自进化**：纠正一次偏好→之后同类生成自动遵守；记忆包裹装配快照可回看；记忆随应用启停零外部服务。— ✅ 蒸馏/规则单测；UI 管理界面 M4
11. **实时体验**：按「整理」到首帧 ≤2s 且过程无白屏；演示片段产出即渐进可见。— ✅ 实时预览/流式事件链路已通；真机计时待 key 联调

## 4. 开发环境与命令

- 前置：**Node.js 24 LTS、pnpm 10**、Git；Electron 锁 43.x（内置 Node 24.17；33 已 EOL，每 2 major 设升级窗口）。
- DSH 复用包锁 `0.1.2-alpha.1`（与 DSH 桌面同款）：dsh-agent-loop / dsh-llm-pi-ai / dsh-tool-web 等（06 D15），升级随 DSH 节奏评估。
- 脚手架：`pnpm create @quick-start/electron`；命令：`pnpm dev / typecheck / lint / test`。
- 记忆引擎包独立：`packages/memory`（可先行开发与单测，无原生依赖）。
- 双端差异统一贴 `WORKFLOW_LESSONS.md`。
