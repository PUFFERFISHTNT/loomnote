# 02 · 产品定义与功能规划（终稿）

> 合并过程稿 01（产品方案）+ 04（功能对标）并同步「Harness Agent」定调后的产品层终稿。技术实现见 03，记忆见 04，执行见 05。

## 1. 产品画像

- **用户**：学生/自学者/研究者/备考者——手里有讲义、论文、网页，需要「整理→学懂→记住→串起来」的人。
- **形态**：Windows + macOS 桌面应用（后续 Web），本地优先，单机可用。
- **差异定位一句话**：<i>Notion 把资料整理成文档，RemNote 把笔记织成记忆网——**织记把资料交给一个会自己上网查证、会画会演、记得你的 agent，直接长出「学得会」的笔记。**</i>
- **三条用户价值**：① 导入即交付（劣质资料 → 成品笔记）；② 演示即理解（看不懂的知识点变成能动的 HTML）；③ 用即生长（笔记网、复习节奏、AI 脾气全部随使用进化）。

## 2. 七大视图（产品界面蓝图）

| 视图 | 核心内容 | 关键交互 |
|---|---|---|
| V1 工作台 | 今日复习队列、学习连续天数、知识网络规模、待整理箱、agent 最近动态（查了什么/整理了什么） | 一键「继续上次」「今日开复习」 |
| V2 资料箱·导入 | 拖拽导入 PDF/Word/Excel/图片/链接；任务队列+进度+重试；按课程/主题自动分组 | 批量导入、失败重试、来源标记 |
| V3 笔记工作区 | 三栏：目录树 ｜ 正文（正文/演示/源码三模式）｜ 关联面板（双链/相关知识点/出处） | 模式切换、AI 整理、导出、同步 |
| V4 学习·演示 | AI 生成的 HTML5 交互演示全屏沉浸；分步推演/动画/图解；卡内自测 | 步骤播放、打断提问（agent 边演示边答） |
| V5 复习中心 | 抽认卡、章节测验、错题本、FSRS 排期日历、薄弱点回炉 | 即时判分、错因解析、排期微调 |
| V6 知识图谱 | 力导向画布：节点=知识点、边=关联（前置/延展/类比/应用）；MOC 地图；孤岛检测 | 缩放/筛选/聚类/点击侧卡；变更集审批 |
| V7 集成与设置 | 模型供应商管理、**agent 工具开关（含联网搜索）与审批设置**、记忆管理、数据备份与导出、引擎状态 | 连通性测试、记忆查看/删除、危险操作白名单 |

## 3. 功能完整度标准（对标权衡）

**必须全有（M1–M4 兑现）**：富文本块全套（标题/列表/引用/代码/表格/高亮/色块/折叠）、目录块、公式 KaTeX、图片规范（居中/等比/并排）、嵌套子页面树、模板库、历史版本+Diff 恢复、全局搜索（FTS5+语义）、多维数据视图（表格/看板/日历）、属性体系（标签/难度/日期/关联）、双链+反链面板、图谱画布、MOC、FSRS 复习+统计面板、导入导出（md+assets/HTML/PDF）。

**AI 增强独有（对标软件没有）**：自动整理生成、动态 HTML 演示、自动打标/建双链/失链检测、注意力+记忆包裹语境注入、表格→结论块、错题归因薄弱点、增量知识合并（找接缝→变更集→审批快照）、偏好自进化、**睡眠计算温习预计算**（到期的复习项提前备好摘要/演示骨架，温习瞬时起页——评审 C 认定的差异化特性，M4 后启用）。

**明确不做（当前阶段）**：多人协作/权限、评论批注、发布为网站、无限白板（图谱承担）、Bitable 级公式自动化。

## 4. 核心工作流的用户体验定义（验收的「感觉」）

1. **整理流**：拖入 PPT/PDF → 待整理箱出现任务 → 按「整理」→ **首帧 ≤2s** → agent 在界面里可见地「干活」（读稿 → 查证补充资料 → 裁剪配图 → 生成笔记与演示），全程一条连续生长流，可打断改要求、可看「它刚查了什么」。
2. **学习流**：打开笔记 → 正文先行；点开演示 → 分步动画；卡内自测即答即判；不懂的直接打字问（agent 带上下文回答，必要时联网查证）。
3. **复习流**：今日队列按 FSRS 出牌 → 判分 → 错题归属薄弱节点 → 图谱与统计同步更新 → 明日队列自动重排。
4. **生长流**：新资料导入 → agent 与存量网比对 → 出变更集（增节点/改节点/建边）→ 用户审批 → 快照落库；期间不整本重写。

## 5. 版本节奏

- **开发测试版（当前目标）**：上述 1、2 流 + 知识网 v1 + 复习 v1，双端 `pnpm dev` 可用；无安装包签名。
- **V1（P2 后）**：飞书/Notion 双向同步、安装包、自动更新。
- **V2（远期）**：Web 端、账号、多人协作评估。
