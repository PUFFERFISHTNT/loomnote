# 07 · Electron 安全基线（终稿）

> 依据评审 B（TOP7-#7）与 C（Artifacts 级沙箱）成文。M0 落地、CI 把关；本文件是「开发测试版」的安全底线，不是可选清单。

## 0. 落地状态（2026-09-18）

- ✅ CSP：主页面含 `frame-src 'self' data: blob:`（否则 data: URL 演示被拦截）；演示 iframe 用 `data:` 文档（不继承父 CSP）+ 注入 meta CSP `default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data: blob:`。
- ✅ 沙箱：sandbox="allow-scripts allow-forms"（永不加 allow-same-origin）+ MessageChannel 桥 + 外联=0 纪律校验（validateDemoHtml，恶意 pattern 单测）。
- ✅ preload：CJS（sandbox 渲染进程必需），contextBridge 只暴露 typed API；webUtils.getPathForFile 仅拖拽路径。
- ✅ 单实例锁 + will-navigate 拦截 + 新窗全拒 + 权限默认拒绝。
- ⏳ 待 M3：密钥 safeStorage 加密（当前明文 JSON）、日志脱敏中间层、静态扫描（electronegativity）。

## 1. 三支柱

1. **进程隔离**：contextIsolation:true、nodeIntegration:false、sandbox:true（渲染层）；主进程独占特权与单写者。
2. **内容隔离**：业务 UI 与 AI 生成的演示内容用不同 CSP 分治——主页面 CSP 允许本地资源+白名单 API；演示 iframe 用隔离域 CSP（见 §2）。
3. **最小授权**：preload 只暴露 typed API（zod 校验入参）；权限按需请求；危险工具一律审批门（见 03 §5.2 工具表）。

## 2. AI 生成内容沙箱（演示模式三件套，评审 B2/C4）

```html
<iframe src="./demo-frame.html"
        sandbox="allow-scripts allow-forms">   <!-- 永不加 allow-same-origin，否则可自我解除沙箱 -->
```

- **帧页注入不可变 meta CSP**（srcdoc/帧页首字节）：
  `default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data: blob:;`
  效果：封死外联 img/script/font/connect——AI 生成的 HTML **无法把任何数据带出本机**。
- **MessageChannel 私有端口桥**替换裸 postMessage：父页创建 `MessageChannel` 并把 `port2` 传入帧页；bridge 事件名白名单 + 载荷 zod 校验；帧页导航即断连。主 webContents 另配 `will-navigate` 拦截 + `setWindowOpenHandler` 全拒 + permission handler 默认拒绝。
- **纪律校验器加「外联资源=0」预检**：检出任何 http(s) 外链/外联资源即判不合格，只重写该段。
- **恶意内容冒烟测试套件**：外联 img/script、link rel=prefetch、form 提交、window.open、导航跳转等 pattern 常驻 CI（M2 起）。

## 3. 主进程安全

- 单实例锁（M0 验收）+ 主进程唯一写句柄。
- `app.on('web-contents-created')`：全站 `will-navigate` 拦截、`setWindowOpenHandler` 拒绝、`session.setPermissionRequestHandler` 白名单。
- 外链一律 `shell.openExternal` 前校验协议白名单（http/https only）。
- 开发模式区分：生产禁 devtools 快捷键（打包阶段启用）。

## 4. 密钥与数据

- LLM 密钥/同步凭证经 **Electron safeStorage**（macOS Keychain / Windows DPAPI）加密落盘，settings 不存明文。
- 日志脱敏中间层：统一 log 出口，正则剥离 key/token/authorization。
- 云端同步排除清单明文定义：**行为流水、规则、上下文快照三表永不出本机**（评审 C 隐私护栏）。

## 5. IPC 纪律

- channel 静态清单（字符串 union）；双向参数 zod 校验；渲染层只经 preload 单入口。
- 流式事件（ai:event 等）走 webContents.send 单通道、载荷大小上限。

## 6. CI 安全门禁

- 依赖审计（pnpm audit）定期跑；原生模块加载冒烟（B4）纳入 M0。
- 引入静电扫描（评审 B 建议的 electronegativity 类工具），**--severity high 不通过不合并**。
- patches/ 内部分支 + semver 锁定，防低活跃依赖带病（B10）。
