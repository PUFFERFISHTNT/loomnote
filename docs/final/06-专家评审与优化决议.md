## 3. 固化的工程纪律（三路共同背书）

1. **证据先行**：任何算法/机制进主线前过 20 行原型 + 基准回归；「效果优先」用数据说话。
2. **P0 机制红线 ≤6**：流内回环 / 渐进渲染 / 特征预分析 / 健康自愈 / 降档路由 / 沙箱三件套——其余全数按阶段排队。
3. **每个里程碑做「删除测试」**：删掉它，哪条验收会挂？挂才留。
4. **合规不变**：CC BY-NC-SA 只借思想与公式；全部 TS 独立实现；启发来源署名。
