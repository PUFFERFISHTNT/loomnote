# AILT9019 final deliverable checklist

This maps repository work to the supplied final rubric, final report template and Week 12 clinic guidance. These documents set course assessment criteria; the user's requested scope defers the product introduction webpage. A repository cannot by itself guarantee a full mark.

The stated deadline is **20 November 2026, 23:59 UTC+8**, with a final ZIP no larger than 100 MB. Check the course submission page for any later changes.

| Deliverable | Status / verification |
|---|---|
| Reproducible implementation | Source, dependencies/lockfile, setup/run/test instructions and public examples are versioned. Check the exact commit's macOS and Windows CI. |
| Complete workflow and boundaries | Import → real generation → interactive output → merge/review/map → restart; desktop tests and recording evidence cover the path. Scanned PDF failure and assessed-exam refusal are distinct cases. |
| Demo recording | Actual Electron recording; see DEMO and measured EVIDENCE. A viewing copy must disclose time compression/restart joins. |
| Public introduction webpage (C1, 8 points) | Deferred at the user's request. README and the desktop UI do not fulfil the separate webpage criterion. |
| Final report (maximum five pages) | Use all seven template sections. Include actual limitations, validation, section-level member contributions and full AI-use disclosure. Do not claim human evaluations that have not happened. |
| Team Zoom presentation (maximum three minutes) | Human deliverable; every member speaks with name visible. Separate from the product demo. |
| Weekly records and contributions | Preserve genuine weekly records. Each member must verify their real contribution. |
| Proposed educational evaluation | Three decks × four requests, three placement raters and an outside-user session need actual people and recorded results. Automated UI checks do not replace them. |
| Submission ZIP | Include only required deliverables; exclude node_modules, keys, user-data folders and raw runtime logs. Verify size and all links before submission. |

AI-assisted implementation and test/recording automation must be disclosed accurately in the final report. Test passes establish the stated technical behaviour, not learning gains, perfect citations or a guaranteed assessment score.
